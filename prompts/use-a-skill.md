# How to Use a Skill Prompt

This repository stores task-focused playbooks in `.claude/skills/`.

Use a skill when you want a checklist, review rubric, or implementation pattern for a focused topic, for example:

- `clean-code`
- `architecture-review`
- `design-patterns`
- `api-contract-review`
- `ef-core-patterns`
- `azure-integration`
- `logging-patterns`
- `testing-patterns`
- `security-audit`

## Example Prompt

```text
Read AGENTS.md and .claude/skills/api-contract-review/SKILL.md.
Use them as the review rubric for these controller changes.
```
